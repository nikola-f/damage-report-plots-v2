# PoC 計測結果

## R1 — CORS プリフライト（認証不要, curl で先行確認済み）

`Origin: https://example.com` 付き OPTIONS プリフライトに対する応答:

| エンドポイント | 結果 | 許可メソッド / ヘッダ |
|----------------|------|------------------------|
| `gmail.googleapis.com/gmail/v1/users/me/threads`（list/get） | ✅ ACAO 反映 | GET ほか / `authorization` |
| `www.googleapis.com/batch/gmail/v1`（**batch**） | ✅ ACAO 反映 | POST ほか / `authorization,content-type` |

→ **プリフライト段階では batch・個別 GET とも CORS 許可**。最大の未知数だった
batch endpoint がブラウザから叩ける見込みが立った。ただし「実認証リクエストが
実際に通り、レスポンスにも ACAO が付くか」はブラウザ実行での確認が必要（下記）。

十分収まる（数分オーダー）。並列 GET フォールバックも温存済み。
